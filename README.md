# Ahmad Bukhari Portfolio

Personal portfolio with mobile application projects, experience, education, and a printable résumé.

Built with HTML and CSS. No dependencies or build step are required.

Open `index.html` locally, or visit the GitHub Pages website after deployment.

## Files

- `index.html` — portfolio
- `resume.html` — printable résumé
- `style.css` — responsive styles
- `assets/` — screenshots from the linked project repositories
